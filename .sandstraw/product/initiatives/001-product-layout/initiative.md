# Product Layout Initiative

## Objective

Organize Sandstraw product artifacts so each initiative owns its own folder, every user story sits beneath it, and every implementation task stays grouped with its task bundle.

## Business value

- Makes ownership and discovery easier for both humans and the orchestrator.
- Keeps each initiative self-contained while preserving shared memory and state at the root of `.sandstraw/`.
- Reduces ambiguity when multiple initiatives exist in the same repository.

## Scope

This initiative covers the artifact hierarchy, documentation updates, and the validation model for nested initiative-to-task ownership.
